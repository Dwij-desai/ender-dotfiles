# EnderOS Roadmap

## v0.1

- Foundation capabilities established
- Design language and tokenized styling stabilized
- Core desktop modules integrated for daily use
- Documentation baseline created

## v0.2

- Infrastructure capabilities established
- Repository governance and automation in place
- Installer and health-check architecture reviewed
- Milestone design review completed

## v0.3

- Developer awareness capabilities
- Git operational visibility
- Container workflow visibility
- Remote systems visibility
- Storage and networking visibility

## v0.4

- Workflow intelligence capabilities
- AI-assisted operational workflows
- Cross-component action orchestration
- Milestone design review completed

## v1.0

- Portable developer workstation at production quality
- Fresh Arch reproducibility validated
- Stable public interfaces for installer and CLI

## Capability Domains

The roadmap is tracked by capabilities instead of fixed feature names.

- Developer Awareness
- Git
- Containers
- Remote Systems
- AI
- Storage
- Networking

Each milestone should end with a design review that validates architecture,
portability, naming consistency, and user experience.
