# EnderOS Components

This document defines the role of each major EnderOS module.

## Runtime Components

- Hyprland: window/session orchestration
- Waybar: desktop instruments
- Walker: launcher and action console
- SwayNC: event and notification center
- Hyprlock: lock screen and secure access

## Shared Foundations

- Theme: shared tokens and style primitives
- Assets: fonts, icons, wallpapers
- Scripts: reusable operational logic

## Infrastructure Components

- Installer scaffold: reproducible setup boundary
- Doctor design: health reporting boundary
- Test scaffold: baseline quality verification

## Ownership Rule

Each responsibility should be owned by one component only.
